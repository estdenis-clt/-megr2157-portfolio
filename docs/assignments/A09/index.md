## Objective


The objective was to design a pulley system given certain parameters using different combinations of variables and concepts including size and materials of each part. We were given a plethora of given values to work with. We had to create a design where both pulleys have a diameter of 3 inches. We then had to select an operating speed between 1000–2000 rpm. We also had to select a belt tension between 4–6 lbf under stationary conditions. We were given a safety factor of 3.

## Frame design:


Now that I had all of my values assembled, it was time to actually put them into a final design. In order to create a design, I did research on what a typical frame pulley looks like and I got a wide array of different designs. Although this wasn't really necessary for the sake of the assignment, I decided to have a system where my pulleys were in between two plates that gives it extra strength and also allows for no bending moment in the shaft, preventing any chances of the belt skipping off the pulleys.
